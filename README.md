# UIDAI Credential Wallet PWA

A Progressive Web Application (PWA) built as part of the Frontend Developer Technical Assessment.

## Features

- Responsive Credential Dashboard
- Context API State Management
- Mock API Integration
- Loading, Error & Empty States
- Secure Data Masking
- Auto Hide after 10 seconds
- Accessibility (WCAG)
- Progressive Web App
- Offline Support using Service Worker
- Automated Testing with Vitest

---

## Tech Stack

- React 19
- TypeScript
- Vite
- Context API
- Service Worker
- Vitest
- React Testing Library

---

## Installation

```bash
git clone https://github.com/jyotheeshmangasamudram/uidai-credential-wallet-pwa.git

cd uidai-credential-wallet-pwa

npm install

npm run dev
```

---

## Run Tests

```bash
npm run test
```
